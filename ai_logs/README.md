# AI chat logs

Exported transcripts of every AI session that contributed to this project (see `docs/AI_USE.md`).

Naming: `YYYY-MM-DD_<short-topic>.<md|json|txt>`, e.g. `2026-11-15_repo-implementation.md`.

Expected entries:

| Session | Status |
| --- | --- |
| Paper discussion and specification drafting (before 2026-11-15) | to be exported by the author |
| 2026-11-15 repository creation and local implementation | to be exported by the author after the session |

Checklist before committing a log:

- [ ] complete transcript (no edited content other than marked redactions)
- [ ] no credentials, tokens, keys, or private URLs
- [ ] private names, hostnames, and home-directory usernames redacted where needed, marked `[REDACTED: reason]`
- [ ] entry added to the table above and to `docs/AI_USE.md`
